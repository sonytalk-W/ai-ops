# About

**AI 運維** is my personal tech blog, documenting real-world experience applying AI to IT operations and cybersecurity work.

## Who I Am

- Current role: cybersecurity software sales rep (self-developed DNS anomaly detection product)
- Day-to-day: visiting clients, demos, debugging, writing automation scripts to save my own sanity
- Interests: automating repetitive work, exploring new tools, writing down every trap I fall into

## Why This Blog

Two reasons:
1. **For future-me** — if I don't write it down, I'll walk into the same trap again
2. **For fellow practitioners** — if you're doing something similar, drop a comment or open a GitHub Issue

## Tech Stack

- Blog: Jekyll + Chirpy + jekyll-polyglot (GitHub Pages)
- Content: primarily Chinese, with English versions for select posts
- Workflow: write in Markdown in this repo, let Jekyll render
