# 關於這個站

**AI 運維** 是我的個人技術部落格，記錄在 IT 運維與資安工作中實際運用 AI 的經驗。

## 我是誰

- 現職：資安軟體 PM
- 平常在做的事：拜訪客戶、Demo、debug、寫些自動化腳本讓自己不要太累
- 興趣：把雜事自動化、研究新工具、把踩過的坑寫下來

## 為什麼寫部落格

兩個理由：
1. **給未來的自己看** — 踩過的坑不記下來，下次還是會踩
2. **給同行交流** — 如果你也在做類似的事，歡迎留言或 GitHub Issue 討論

## 技術棧

- 部落格：Jekyll + Chirpy + jekyll-polyglot（GitHub Pages）
- 內容：以中文為主，部分文章有英文版
- 工作筆記：用 Markdown 寫在這個 repo，再透過 Jekyll 渲染
